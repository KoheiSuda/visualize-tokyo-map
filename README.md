# 東京都の営業時間の可視化

## システム概要

東京都内における様々な業種（ラーメン、居酒屋、カフェ、歯医者、ガソリンスタンド）の店舗の営業時間を地図上でインタラクティブに可視化する Web アプリケーション

## 背景

Google Map などの既存の地図サービスでは、広範囲における特定業種の店舗分布を一目で把握したり、地域ごとの営業時間の傾向を比較したりすることが困難だったため 本これらの課題を解決し、以下の目的を達成するためにシステムを構築しました。

-   指定した時刻に営業している店舗を地図上に表示する。
-   店舗のジャンルごとに、営業時間や分布の傾向を比較・分析する。
-   地域特性（駅からの距離、路線など）と店舗の分布・営業時間の関連性を探る。

## データセット

本システムでは以下のデータソースを利用しています。
店舗情報（位置、営業時間）

-   ラーメン、居酒屋、カフェ: 食べログ (https://tabelog.com/)
    店舗ごとに表記形式が異なる営業時間は、LLM を用いて統一形式に整形。
-   歯医者: Doctors File (https://doctorsfile.jp/)
-   ガソリンスタンド: gogo.gs (https://gogo.gs/)
-   駅・路線図情報:駅データ.jp (https://ekidata.jp/)
-   地図情報:国土数値情報ダウンロードサイト (https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-v3_1.html)
    geojson 形式の白地図データを取得し、D3.js および Leaflet.js で描画。

## 使用技術・ライブラリと独自実装

主な使用ライブラリ:D3.js: 地図描画、店舗・駅・路線図のマッピング、時計 UI の描画
Leaflet.js: 詳細地図の表示、ズーム機能、SVG オーバーレイ
参考にした既存コード:時計のデザイン: Simple Clock / D3 / Observable デザインの基本的なアイデアを参考にしましたが、時刻と地図表示の連動、針のインタラクティブ操作（ドラッグ、時刻メモリクリックによるジャンプ）、自動再生機能は独自に実装しました。
Leaflet と SVG の連携: Leaflet.js で SVG 要素をオーバーレイする | Gunma GIS GEEKLeaflet の初期設定、タイルレイヤー設定、SVG レイヤーの追加方法を参考にしました。地図と時計の連動、ジャンル選択、表示要素の切り替えなど、他の機能連携は独自に実装しました。
時刻（時計 UI）と地図上の店舗表示の完全な同期。
インタラクティブな時計 UI（針のドラッグ操作、時刻メモリクリックによるジャンプ、再生/一時停止）。
ジャンル選択機能とそれに応じた店舗表示のフィルタリング。
曜日選択機能と営業時間データの連動。
地図のズームレベルに応じた表示の最適化。
駅・路線図データの表示/非表示切り替え機能。
メインマップ上のダブルクリックによる Leaflet 詳細地図への遷移。
詳細地図上での店舗アイコンへのマウスホバーによる店舗詳細情報（ジャンル、店名、営業時間）のポップアップ表示。
店舗を表す円の半径・透明度を調整可能なスライダー UI。
